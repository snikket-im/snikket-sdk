# Borogove

Borogove is a high-level headless chat SDK for building chat apps or chat experiences into other apps, backed by any Snikket-compatible server.

## Dependencies

* libdatachannel-dev
* libmbedtls-dev
* libopus-dev
* libpcre2-dev
* libsqlite3-dev
* libstrophe-dev

## Building

    make -j$(nproc)
